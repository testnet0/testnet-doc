# 资产管理概述

> 🖼️ **[Screenshot Placeholder]**: 请在此处补充相关界面的截图 (e.g. `![界面截图](/images/screenshot.png)`)


资产管理是 TestNet 的核心模块，支持对企业网络资产进行系统化的录入、发现、分类与管理。

## 资产模型与关系图谱

TestNet 拥有完整的 **8 大核心资产模型**。系统会根据“公司 ➡️ 主域名 ➡️ 子域名 ➡️ IP ➡️ 端口 ➡️ Web ➡️ API/漏洞”的关联关系，自动生成清晰的网络资产结构图谱。

> [!TIP] 📐 资产模型与关联规则详解
> 关于 8 种资产的具体字段定义、唯一指纹标识规则及上下游层级绑定逻辑，请参阅核心模型专篇：**[资产图谱模型说明 (Asset Models)](/assets/models)**。

## 通用操作

所有资产类型均支持以下操作：

### 列表操作

| 操作 | 说明 |
|------|------|
| **搜索** | 关键字模糊搜索 |
| **高级筛选** | 多条件组合筛选（标签、状态、时间等） |
| **排序** | 点击列标题排序 |
| **分页** | 调整每页条数（10/20/50/100） |
| **导出** | 导出为 Excel 文件 |
| **导入** | 从 Excel 批量导入 |
| **新增** | 手动添加单条记录 |

### 批量操作

选中多条记录后可执行：

| 操作 | 说明 |
|------|------|
| **批量删除** | 删除选中的资产 |
| **批量标签** | 为选中资产添加/移除标签 |
| **批量分配** | 将资产分配到指定项目 |
| **批量执行** | 对选中资产执行工作流 |

### 单条操作

| 操作 | 说明 |
|------|------|
| **编辑** | 修改资产字段 |
| **删除** | 删除单条资产 |
| **查看详情** | 查看完整字段与关联资产 |
| **变更历史** | 查看资产的历史修改记录 |

## 资产规则

资产规则引擎在资产保存时自动执行，支持以下规则类型：

### 验证规则（BLOCK）

拒绝不符合条件的资产写入：

**示例**：只允许录入公网 IP
```
条件: asset.isPublic == false
操作: BLOCK（拒绝保存）
```

### 标签规则（TAG）

自动为资产添加标签：

**示例**：包含 `api` 的子域名自动打标签
```
条件: subdomain contains "api"
操作: 添加标签 "API资产"
```

### 所有权规则（OWNER）

自动分配资产负责人：

**示例**：金融子域名分配给安全组
```
条件: domain endsWith ".finance.example.com"
操作: 分配所有者 "security-team"
```

## 资产标签

标签是灵活的分类方式，可用于筛选和批量操作。

### 添加标签

- **手动添加**：在资产详情中点击「**+ 标签**」
- **批量添加**：选中多条记录后执行「**批量标签**」
- **自动打标**：配置资产标签规则自动匹配

### 使用标签筛选

在列表页顶部的标签筛选下拉中选择标签，快速过滤资产。

## 导入导出

### Excel 导入

1. 点击「**导入**」→「**下载模板**」
2. 按模板格式填写数据（必填字段标有 *）
3. 上传 Excel 文件
4. 查看导入预览和结果统计

**导入结果说明**：

| 状态 | 说明 |
|------|------|
| ✅ 已保存 | 成功创建新资产 |
| ⏭️ 已跳过 | 资产已存在（去重） |
| 🚫 已拦截 | 被资产规则拒绝 |

### Excel 导出

点击「**导出**」按钮，将当前筛选结果导出为 Excel 文件（最多 10,000 条）。

## 变更历史

每次对资产的新增、编辑、删除操作都会自动记录变更历史：

1. 打开资产详情
2. 点击「**变更历史**」抽屉
3. 查看操作时间、操作人、变更内容
