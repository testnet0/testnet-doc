# 资产操作与管理实践 (Asset Operations)

TestNet 资产中台提供了面向海量资产的高效运维与管理工具链，涵盖 **批量导入导出 (Excel/CSV)**、**跨维度批量修改与打标** 以及 **全生命周期审计追踪 (History AOP)**。

---

## 一、 批量导入与导出

TestNet 提供了高性能流式数据处理功能，支持在低内存消耗下高效完成海量资产记录的导入与离线导出。

### 1. Excel 导入流程与模板规范
在任何资产列表顶部，点击 **「导入 Excel」** 即可下载模板并批量上传数据：
- **必填字段校验**：主域名 (`domainName`)、子域名 (`subdomain`) 等实体关键字段为必填；
- **智能标签拆分**：Excel 中多个标签可用英文逗号 `,` 或分号 `;` 分隔（如 `核心业务,高防CDN`），系统导入时将自动切分为 JSON 数组；
- **自动排重与更新策略**：如果导入的资产标识（如 IP/端口对或主域名）已在当前 `projectId` 下存在，系统将自动触发合并与更新规则。

### 2. 导出与查询范围联动
点击 **「导出 Excel」** 可以将当前筛选结果（包含搜索条件、标签过滤器、状态分类）整体导出成 `.xlsx` 文件，可用于离线归档和合规审计报告。

---

## 二、 批量操作与进度追踪

当需要对成百上千个资产同时执行标签调整、状态修改或归属项目迁移时，可以使用 **批量操作助手 (BatchActions)**：

### 1. 勾选与作用域选择
通过列表框左侧的复选框，用户可选定：
- **当前页选中**：操作所勾选的项；
- **全选过滤结果**：对当前高级筛选匹配出的全部总条数（如满足某标签的 5000 个资产）执行批量指令。

### 2. 批量处理进度控制
在提交批量打标 (`tags`) 或归属修改后，界面将弹出 **批量进度条模态框 (BatchActionModal)**。系统通过分布式异步任务分批处理，并实时回显操作进度：
- **处理总数 / 成功数 / 跳过数**：实时观察数据变更情况；
- **自动规则触发**：批量添加资产完成后，系统会自动发起一次后台验证，对符合条件的资产执行 [资产规则](/assets/rules) 打标。

---

## 三、 变更历史记录与审计

TestNet 对每一个核心资产的所有增删改操作进行全量追踪。无论由控制台手工修改，还是由节点自动化扫描任务上报，系统都会自动记录变更日志，形成完整的审计轨迹。

### 查看变更轨迹 (AssetHistoryDrawer)
在资产列表中点击任意条目的 **「历史记录」** 操作按钮，将自右侧弹出变更轨迹抽屉：
1. **操作时间与执行人**：明确记录是由哪个用户或具体任务 ID (`Task #XXXX`) 发起的变更；
2. **前后快照对比 (Diff)**：精细展示各字段的值变更变化（如 `status: PENDING -> ACTIVE`，或 `tags: ["新发现"] -> ["新发现", "已确认"]`）；
3. **版本回滚**：当某个误操作导致重要资产属性被覆盖时，运维人员可在历史记录中选择目标版本点击 **「回滚」**， 把资产恢复到该历史快照的状态（标签、归属、状态等字段均会恢复）。
