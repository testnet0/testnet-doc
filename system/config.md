# 系统配置

系统配置用于设置平台的全局参数，包括邮件服务、通知配置等。

## 邮件服务配置

配置 SMTP 邮件服务器，用于：
- 发送通知邮件
- 用户密码重置（如支持）

### 配置步骤

1. 进入「**系统管理**」→「**系统配置**」→「**邮件设置**」
2. 填写 SMTP 配置：

| 配置项 | 说明 | 示例 |
|--------|------|------|
| **SMTP 服务器** | 邮件服务器地址 | `smtp.gmail.com` |
| **SMTP 端口** | 服务端口 | `465`（SSL）/ `587`（TLS） |
| **加密方式** | SSL / TLS / 无 | `SSL` |
| **发件人邮箱** | 发送通知的邮箱 | `testnet@yourcompany.com` |
| **发件人名称** | 显示的发件人名称 | `TestNet 通知` |
| **账号** | SMTP 认证账号 | 通常与发件人邮箱相同 |
| **密码** | SMTP 认证密码 | SMTP 授权码 |

3. 点击「**发送测试邮件**」验证配置是否正确
4. 保存配置

### 常见邮件服务商配置

::: code-group

```text [Gmail]
SMTP 服务器: smtp.gmail.com
端口: 465 (SSL) 或 587 (TLS)
账号: 您的 Gmail 地址
密码: 应用专用密码（需开启两步验证后生成）
```

```text [企业邮箱 (腾讯)]
SMTP 服务器: smtp.exmail.qq.com
端口: 465 (SSL)
账号: 企业邮箱地址
密码: 邮箱密码
```

```text [阿里云企业邮箱]
SMTP 服务器: smtp.mxhichina.com
端口: 465 (SSL)
账号: 企业邮箱地址
密码: 邮箱密码
```

:::

## 系统参数

进入「**系统参数**」可配置：

| 参数 | 说明 |
|------|------|
| **任务超时** | 全局默认任务超时时间 |
| **最大并发任务** | 单个节点最大并发任务数 |
| **日志保留天数** | 任务日志保留时间 |
