# 仪表盘

仪表盘是 TestNet 登录后的默认首页，展示平台整体数据概况与最近活动，帮助您快速了解资产规模、任务状态和系统健康情况。

## 数据统计面板

::: info [图片占位：控制台仪表盘概览]
:::

仪表盘顶部展示资产数量的全局统计卡片：

| 统计指标 | 说明 |
|---------|------|
| **公司** | 当前项目下的公司数量 |
| **主域名** | 当前项目下的顶级域名数量 |
| **子域名** | 当前项目下的子域名数量 |
| **IP** | 当前项目下的 IP 数量 |
| **端口** | 当前项目下的开放端口数量 |
| **Web** | 当前项目下的 Web 应用数量 |
| **API** | 当前项目下的 API 接口数量 |
| **漏洞** | 当前项目下的漏洞数量 |

::: info [图片占位：数据统计卡片面板]
:::

::: tip 项目过滤
仪表盘数据默认显示**当前选中项目**的统计信息。通过顶部导航栏的项目切换器切换项目后，数据会自动更新。
:::

## 近期任务概览

展示最近执行的扫描任务状态分布：

| 状态 | 图标 | 含义 |
|------|------|------|
| RUNNING | 🔄 | 正在执行的任务数 |
| COMPLETED | ✅ | 今日完成的任务数 |
| FAILED | ❌ | 今日失败的任务数 |
| PENDING | ⏳ | 等待分配的任务数 |

点击状态卡片可快速跳转到「**任务管理**」并按对应状态筛选。

---

## 节点状态

展示当前在线的扫描节点数量和总节点数：

```
在线节点: 3 / 5 总节点
```

- 🟢 **在线**：正常运行，可接受任务
- 🔴 **离线**：超过 5 分钟未上报心跳

点击可跳转到「**扫描节点**」管理页面。

---

## 最近活动

展示平台近期的操作记录和自动化事件：

- 工作流执行开始/完成通知
- 新资产发现记录
- 系统重要事件提醒
