# 界面概览

本页介绍 TestNet 的主要界面区域和核心交互方式，帮助您快速熟悉操作环境。

## 整体布局

TestNet 采用经典的管理后台布局：

- **顶部导航栏**：项目切换器、通知、用户信息
- **左侧菜单栏**：主要功能模块导航
- **主内容区**：当前模块的内容和操作

## 顶部导航栏

### 项目切换器

顶部左侧显示当前项目名称，点击可切换到其他项目。

::: tip
切换项目后，资产列表、工作流、任务等数据会自动过滤为当前项目的数据。
:::

### 通知铃铛 🔔

显示未读通知数量。点击可查看：
- 任务完成通知
- 工作流执行状态
- 系统告警信息

### 用户菜单 👤

点击右上角头像可访问：
- **个人设置**：修改个人信息和密码
- **退出登录**

## 仪表盘（控制台首页）

登录系统后默认进入首页仪表盘（Dashboard），它通过数据统计卡片和图表，实时展示当前项目的资产数量、任务运行状态以及扫描探针是否在线。

> [!TIP] 💡 统计指标与卡片详情
> 关于首页八大资产数据指标说明、扫描任务过滤视角及探针监控详情，请查阅首页专篇：**[控制台与仪表盘](/guide/dashboard)**。

## 列表页通用操作

所有资产列表页具有统一的操作区域：

### 搜索与筛选

```
[搜索框]  [高级筛选▼]  [状态▼]  [标签▼]
```

- **关键字搜索**：在搜索框输入关键词快速过滤
- **高级筛选**：展开多条件组合查询构建器
- **状态下拉**：按资产状态快速筛选
- **标签下拉**：按资产标签筛选

### 操作按钮区

```
[商店]  [导入]  [导出]  [新增]
```

| 按钮 | 说明 |
|------|------|
| 商店 | 打开工具/工作流商店（工具和工作流页面） |
| 导入 | 从 Excel 批量导入数据 |
| 导出 | 将列表数据导出为 Excel |
| 新增 | 创建新记录 |

### 表格操作

| 操作 | 说明 |
|------|------|
| 勾选复选框 | 选中记录，启用批量操作 |
| 点击列标题 | 按该列排序（再次点击切换升/降序） |
| 点击操作列图标 | 编辑、删除、查看详情等 |
| 调整分页 | 底部分页栏调整每页条数和翻页 |

### 批量操作

选中多条记录后，顶部出现批量操作栏：

```
已选 3 条  [全选本页]  [全选查询结果]  |  [批量删除]  [批量标记]  [分配项目]
```

::: warning 注意
「全选查询结果」会选中满足当前筛选条件的**所有**记录，而非仅当前页，批量操作时请谨慎确认。
:::

## 详情页

点击资产或记录可打开详情侧边栏或跳转到详情页，通常包含：

- **基本信息**：字段详情
- **关联资产**：上下游关联关系
- **变更历史**：历史操作记录
- **标签**：资产标签管理

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `/` 或 `Ctrl+K` | 聚焦搜索框 |
| `Esc` | 关闭当前弹窗/抽屉 |

## 主题切换

点击顶部右侧的 🌙/☀️ 图标可切换深色/浅色主题。
