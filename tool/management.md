# 工具商店与配置维护 (Tool Management)

TestNet 平台将具体扫描引擎（如 Nuclei, Nmap, Subfinder）解耦为独立的 Tool 模块。运维与安全人员可以通过 **内置/远端商店管理**、**默认执行参数模板** 以及 **远端配置文件同步 (`configfile`)**，实现对全网扫描工具链的集中式治理。

---

## 一、 工具商店与在线升级 (StoreDrawer)

在 **「工具管理」->「工具列表」** 右上角点击 **「商店 (StoreDrawer)」** 即可打开工具商店抽屉：
- **版本化规范包**：商店直接从远端或本地的 `testnet-registry` 加载，每个工具以版本命名（如 `1.0.0.yaml`）；
- **一键安装与平滑升级**：如果平台检测到远端仓库发布了新版执行参数或新规则包（例如 `nuclei 3.3.0.yaml`），可点击 **「更新」** 热加载最新语法包，无需重启后台 Spring Boot 容器或 Go 客户端。

---

## 二、 工具默认执行配置与参数调优

点击列表中任意工具的 **「配置」** 或在 `ToolEditor` 中，可以为团队设定通用的默认参数与运行策略：
- **默认超时与重试次数 (`Timeout & Retries`)**：设置底层执行命令最大耗时（如 `600s`）以及遇到网络超时或瞬时故障时的指数退避自动重试策略；
- **环境变量注入屏蔽**：可配置 `TESTNET_` 等前缀变量的安全过滤规则，确保扫描器在执行 CLI 命令行时不会泄露主机环境中的敏感变量；
- **资源限额预设**：为 Docker 容器类型工具预设最大内存 (`Memory Limit`) 与 CPU 占有率，防止在高并发爆破或大网段扫描时将底层节点系统拖垮。

---

## 三、 配置文件远端同步与分发

对于需要挂载外部复杂规则库或特定配置字典的工具（例如 **Nuclei 模板目录 `nuclei-templates`**、**字典文件 `wordlists.txt`**、**API 密钥文件 `provider-config.yaml`** 等），TestNet 提供了专门的 **配置文件远端同步与分发模块**：

### 1. 远端文件版本控制与 SHA-256 校验
- 在菜单 **「配置文件管理」** 中，您可以上传或编写任何文本/二进制配置文件包；
- 每次修改更新保存后，系统自动生成该配置文件的唯一 `SHA-256` 散列校验码，并在底层以 `symlink` 符号链接的形式记录历史版本路径。

### 2. 扫描节点启动时自动校验与加载
- 当 Go 客户端 (`testnet-client`) 接收到下发的扫描任务单时，任务信封 (`Envelope`) 会附带当前任务所需挂载的 `configfile` ID 与目标 `SHA-256` 校验码；
- 节点引擎会自动比对本地缓存，若本地不存在或散列码变动，将安全经由 HTTPS 从服务端异步下载拉取，并精准挂载到 Docker 容器的指定只读卷中（如 `/root/.config/nuclei/`）。这保证了全网成百上千个探针节点在执行同一扫描策略时，规则库始终保持绝对一致！
