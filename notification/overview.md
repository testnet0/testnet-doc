# 通知中心

TestNet 提供站内通知、邮件通知、Webhook 通知三种方式，帮助您及时了解任务执行状态和系统事件。

## 查看站内通知

点击顶部导航栏右侧的 🔔 铃铛图标：

- **未读数角标**：显示当前未读通知数量
- **通知列表**：显示最近的通知记录
- **标记已读**：点击单条通知或「全部已读」
- **查看全部**：跳转到通知管理页面查看完整历史

### 通知类型

| 类型 | 触发事件 | 说明 |
|------|---------|------|
| ✅ **新发现资产** | `NEW_ASSET` | 工作流运行发现新资产 |
| ⚠️ **新发现漏洞** | `NEW_VUL` | 扫描发现新漏洞 |
| 🔴 **节点离线** | `NODE_OFFLINE` | 扫描节点超时未上报心跳 |
| ❌ **任务失败** | `TASK_FAILED` | 任务执行失败（含熔断触发） |
| ✅ **任务完成** | `TASK_COMPLETED` | 任务执行成功完成 |
| ❌ **工作流失败** | `WORKFLOW_FAILED` | 工作流运行失败 |
| ✅ **工作流完成** | `WORKFLOW_COMPLETED` | 工作流运行成功完成 |
| ❌ **测试失败** | `TEST_FAILED` | 测试用例执行失败 |
| ✅ **测试完成** | `TEST_COMPLETED` | 测试用例执行完成 |

### 系统告警（WebSocket 实时推送）

节点离线、任务熔断等高优先级告警通过 WebSocket `/topic/system-alert` 实时推送，在页面右上角弹出提示。

## 配置邮件通知

### 配置邮件服务器

1. 进入「**系统管理**」→「**系统配置**」→「**邮件设置**」
2. 填写 SMTP 配置：
   - **SMTP 服务器**：如 `smtp.gmail.com`
   - **端口**：`465`（SSL）或 `587`（TLS）
   - **发件人邮箱**：发送通知的邮件地址
   - **账号/密码**：SMTP 认证信息
3. 点击「**测试发送**」验证配置
4. 保存配置

### 配置通知规则

通知规则配置位于 **「资产管理」→「资产配置」→「通知联动」** 页面（复用资产配置体系，`configType=NOTIFICATION`）：

1. 进入「**资产管理**」→「**资产配置**」→「**通知联动**」
2. 点击「**新建**」创建通知规则
3. 配置：
   - **触发事件**：工作流完成、任务失败、节点离线等
   - **通知方式**：邮件
   - **收件人**：选择用户或手动填写邮箱
4. 保存规则

## 配置 Webhook 通知

Webhook 可将通知推送到企业微信、钉钉、飞书、自定义系统等。

### 配置 Webhook

1. 进入「**资产管理**」→「**资产配置**」→「**通知联动**」
2. 点击「**新建**」创建通知规则
3. 选择通知方式为「**Webhook**」
4. 填写 Webhook URL
5. （可选）配置自定义 HTTP 头
6. 选择触发事件
7. 保存

### 常用 Webhook 示例

::: code-group

```text [企业微信]
https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=YOUR_KEY
```

```text [钉钉]
https://oapi.dingtalk.com/robot/send?access_token=YOUR_TOKEN
```

```text [飞书]
https://open.feishu.cn/open-apis/bot/v2/hook/YOUR_TOKEN
```

:::

## 通知历史

进入「**系统管理**」菜单下的「**消息中心**」（`/notification`）可查看所有历史通知：

- 按类型筛选（新资产、新漏洞、节点离线等）
- 按时间范围筛选
- 查看通知详情和发送状态（成功/失败）
- 支持批量删除历史通知
