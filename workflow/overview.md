# 工作流概述

> 🖼️ **[Screenshot Placeholder]**: 请在此处补充相关界面的截图 (e.g. `![界面截图](/images/screenshot.png)`)


工作流是 TestNet 的自动化核心，通过 DAG（有向无环图）编排多个工具，实现端到端的自动化资产发现与安全扫描。

## 核心概念

### 工作流（Workflow）

工作流由一系列**节点**组成，节点之间通过**依赖关系**和**数据流**连接，形成有向无环图（DAG）。

```
[Subfinder] → [Httpx] → [Nuclei]
      ↘                 ↗
       [Amass] → [Dnsx]
```

### 节点（Node）

每个节点对应一个**工具**的调用，可以配置：
- 输入来源（来自上游节点输出或外部输入）
- 参数覆盖（修改工具默认参数）
- 超时和重试策略

### 触发方式

| 类型 | 说明 |
|------|------|
| **手动触发** | 用户手动执行，需要选择输入资产 |
| **定时触发** | 按 Cron 表达式定期自动执行 |
| **自动触发** | 新资产创建时自动触发（资产联动） |

---

## 工作流生命周期

```
草稿 → 已启用 → 执行中 → 已完成
              ↓
           已停用（暂停定时/自动触发）
```

## 预置工作流

TestNet 工具商店提供 **8 个预置工作流**，可直接安装使用：

| 工作流 | 说明 | 适用场景 |
|--------|------|---------|
| **域名侦察流水线** | 子域名发现 + Web 探测 | 域名资产全面发现 |
| **完整资产发现** | 从公司到漏洞的完整链路 | 新项目初始扫描 |
| **端口扫描工作流** | IP 端口发现 + 服务识别 | IP 资产端口扫描 |
| **Web 攻击面探测** | Web 应用信息采集 | Web 资产盘点 |
| **IP 深度盘点** | IP 端口服务全面扫描 | IP 资产深度扫描 |
| **子域名接管监控** | 定期检测接管风险 | 持续监控 |
| **深度资产监控** | 周期性资产变化监控 | 定时监控 |
| **全自动扫描** | 全流程自动化 | 综合扫描 |

## 快速开始

### 安装预置工作流

1. 进入「**工作流**」→「**工作流列表**」
2. 点击「**商店**」
3. 选择「**域名侦察流水线**」→「**安装**」

### 执行工作流

1. 在工作流列表中找到已安装的工作流
2. 点击「**执行**」
3. 选择输入资产（如目标主域名）
4. 点击「**确认执行**」

### 查看执行结果

1. 进入「**任务管理**」
2. 查看工作流产生的各个工具任务
3. 任务完成后查看发现的资产
