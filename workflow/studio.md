# 工作流工作室与调试 (Workflow Studio)

TestNet 采用合约驱动（Contract-Driven）的 **vNext DAG 工作流引擎**，允许安全人员通过高度可视化的在线代码编辑器（FlowEditor）快速创建、验证与执行自动化编排任务。

---

## 一、 工作流的创建与导入

进入菜单 **「工作流管理」->「工作流列表」**，您可以多种方式新建或引入工作流：

1. **全新创建**：点击右上角 **「新建工作流」**，系统将生成一份带有基础 DAG 控制流（如目标输入 -> 子域名扫描 -> 漏洞探测）的 YAML 初始骨架。
2. **从远端 Registry 商店安装**：点击 **「商店抽屉 (StoreDrawer)」**，可从官方更新库一键导入经严格安全测试的内置 8 大标准渗透测试工作流。
3. **本地 YAML 文件导入/导出**：支持直接导入现成的 YAML 定义文件，或将当前调校完成的工作流导成本地文件与团队成员协同分享。

---

## 二、 在线编辑器与实时 Schema 验证

工作流的核心编辑界面是由高性能代码引擎驱动的 **FlowEditor**，具备 IDE 级的使用体验与实时校验机制：

### 1. 实时语法与控制流依赖诊断
系统内置了 `VNextDslValidator` 在线校验引擎，通过 WebSocket/HTTP 即时对输入的 YAML 代码进行解析：
- **循环依赖检测**：检测 `dependsOn` 中是否存在死循环（如 A 依赖 B，B 又依赖 A）；
- **参数数据流映射检查**：当配置了从上一阶段步骤变量传递参数（如 `inputs.targetDomain.from: "subdomain-enum.output.domains"`）时，实时检查父节点与输出字段是否存在；
- **智能提示与自动补全**：根据内置的 ToolSpec 清单自动提示可调用的 `toolId` 及对应入参名称。

### 2. 验证图览板 (VerifyPanel)
点击页面底部的 **「验证与预览 (Verify)」** 按钮，系统将在侧边展开 `VerifyPanel`：
- **DAG 执行结构化图示**：将代码转化为直观的步骤卡片，清晰呈现步骤的前后依赖关系及并发分叉结构；
- **错误定位跳转**：如果 YAML 存在语法或业务校验错误，面板会列出具体的行号与错误描述，点击即可一键使光标定位到错误代码行。

---

## 三、 工作流的立即执行与运行参数配置

确认 DSL 校验通过（无语法错误）后，即可在编辑器顶部点击 **「立即执行 (Run)」** 发起自动化任务调度。

### 1. 目标变量输入与运行上下文
系统将弹出 **执行配置模态框 (ExecuteTestModal)**，供用户为本次运行指定输入上下文：
- **手动输入目标**：直接在文本框输入要扫描的目标公司名称、主域名（如 `testnet-project.com`）或 IP 网段；
- **资产池联动选择**：可勾选并拉取已有资产图谱中的目标，系统会自动调用 `TargetResolverEngine` 解析出上下游数据注入至工作流的输入上下文（`inputs`）。

### 2. 执行下发与节点隔离调度
点击确认运行后，后端 `WorkflowRunEngine` 引擎将生成一份完整的 **执行信封 (Execution Envelope)**：
- 将任务拆解为细粒度的底层任务单 (`Task`)，下发到对该项目可见、且健康心跳正常的 [Go 扫描节点 (/client/overview)](/client/overview)；
- 如果配置了多分支并行扫描，调度服务 (`TaskDispatcherService`) 会自动多节点负载均衡执行，大幅提升大规模测绘与漏洞评估效率。
