# 任务管理概述

任务（Task）是工作流中每个节点执行的最小单元，代表对一个工具的一次具体调用。

## 任务与工作流的关系

```
工作流执行 #001
  ├── 节点: subfinder（3个输入域名 → 3个任务）
  │     ├── 任务 #001: subfinder(example.com)  ✅
  │     ├── 任务 #002: subfinder(test.com)     ✅
  │     └── 任务 #003: subfinder(demo.com)     🔄
  └── 节点: httpx（来自subfinder输出 → N个任务）
        └── 任务 #004: httpx(...)              ⏳
```

## 任务列表

进入「**任务管理**」查看所有任务：

### 任务状态

| 状态 | 图标 | 说明 |
|------|------|------|
| **PENDING** | ⏳ | 待执行，等待节点分配或上游完成 |
| **ASSIGNED** | 📌 | 已分配到扫描节点，等待执行 |
| **RUNNING** | 🔄 | 正在执行中 |
| **COMPLETED** | ✅ | 执行成功 |
| **FAILED** | ❌ | 执行失败 |
| **SKIPPED** | ⏭️ | 因条件不满足或无输入而跳过 |

### 筛选任务

| 筛选维度 | 说明 |
|---------|------|
| **状态** | 按任务状态筛选 |
| **工具** | 按工具名筛选 |
| **时间范围** | 按创建或完成时间筛选 |
| **项目** | 按归属项目筛选 |
| **节点** | 按执行节点筛选 |

## 任务信息

### 基本信息

| 字段 | 说明 |
|------|------|
| **任务 ID** | 全局唯一标识 |
| **工具名称** | 执行的工具 |
| **所属工作流** | 来源工作流（手动执行任务无此字段） |
| **执行节点** | 哪个扫描节点执行了此任务 |
| **创建时间** | 任务创建时间 |
| **开始时间** | 实际开始执行时间 |
| **完成时间** | 任务完成时间 |
| **执行时长** | 总耗时 |

### 输入参数

查看工具实际接收到的输入资产和参数。

### 输出结果

任务完成后查看：
- **原始输出**：工具的原始标准输出
- **解析结果**：经过解析器处理后的结构化数据
- **保存资产**：成功保存到数据库的资产列表
